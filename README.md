# DataFix

## Description

Application web pour corriger les fichier excel.

## Objectifs

- Corriger les erreurs de doublant
- Remplir les colonnes vides
- Corriger les email, telephone, date
- faire respecter le typage de chaque colonnes
- Uniformer les donnes
- Suprimer les espacements

## Fonctionnalites

- Importer des fichiers xlsx, xls et csv
- Suivi des changements executer
- Suppresion des doublant
- Typage de chaque colonne
- Reconnaisance et correction automatique des emails, telephone, date
- Exportation en fichier xlsx

## Technologies

- React 
- Django
- Panda
- Tailwindcss

## Installation

### backend

cree une environnement virtuelle avec python puis installe Django, panda, djangorestframework et django-cors-headers

- python -m venv env
- pip install Django, panda,djangorestframework, django-cors-headers

### frontend

installer les depandances
- pip install
